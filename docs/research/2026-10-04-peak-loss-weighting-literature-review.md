# 피크 과소예측 손실의 가중치: 선행연구 검토

> 2026-10-04 현재 결정: 새 부스팅 학습·주 평가에서 RF 참조 확률 인자를 제거했다. 아래 문헌·과거 수식은 근거 이력이며 RF 인자 재실험을 요구하지 않는다. [현재 방향](<<PROJECT_ROOT>/notebooks/models/boosting/README.md>).

- 작성일: 2026-10-04, Asia/Seoul.
- 상태: 문헌·원 논문 본문 확인 및 적용 판단 완료. **새 모델 학습 0회**.
- 질문: 피크 과소예측을 줄이려는 예측 연구에서 무엇에 가중치를 주고, 수식·설정값을 어떤 근거로 정하는가?
- 관련 설계: [전체 C 부스팅 실험 설계](<<PROJECT_ROOT>/docs/superpowers/specs/2026-10-04-boosting-full-c-training-design.md>).
- 이 문서는 기존 C·B·분할·대표 선정 결과를 변경하지 않는다. 아래 적용안은 **수정 제안**이며 검증된 최적 설정이 아니다.

## 1. 확인 결과

검토한 여섯 연구에서는 실제 오차 비용에서 벌점을 유도하거나, 실제 목표값의 크기·피크 구간을 기준으로 가중하거나, 검증 손실을 줄이도록 표본 가중치를 학습한다. **현재 식 `1+(cap−1)×clip((y/B−.8)/.2,0,1)×(1+p_RF)/2`와 동일한 근거는 확인하지 못했다.** RF 확률 결합, 80%부터의 선형 증가, 상한 2가 함께 검증된 표준식이라고 설명할 수 없다. 이 조사로 해당 식을 사용하는 연구가 전혀 없다는 사실까지 증명한 것은 아니다.

문헌의 숫자보다 중요한 것은 선정 절차다. 비용이 확인되면 그 비용으로 정하고, 비용이 없으면 단순한 형태의 작은 후보 집합을 과거 학습·검증 구간에서 비교한다. 다른 데이터의 최적 가중치를 공장 데이터의 최적값으로 가져오지 않는다.

## 2. 먼저 구분할 세 가지 가중치

| 구분 | 예시 | 현재 C에서의 위치 |
|---|---|---|
| 손실 항의 결합 계수 | 평균·꼬리·피크의 상대 중요도 | 0.5 / 0.3 / 0.2 |
| 오차 방향의 벌점 비율 | 과소예측을 과대예측보다 비싸게 평가 | max(y−prediction,0)의 비대칭성 |
| 피크 표본의 중요도 | 실제값이 큰 셀에 추가 중요도 부여 | L_peak 내부의 w_i |

논문의 과소/과대 비용 비율 7.5, 피크 MAE 가중치 2, 전체 C의 계수 0.2는 같은 숫자 종류가 아니다. C에서 w를 모든 셀에 동일하게 λ배 하면 L_peak는 λ배가 아니라 **sqrt(λ)배**가 된다. 표본 일부만 가중하면 gradient 분포와 L_peak 분모·norm까지 함께 작용한다.

## 3. 논문별 확인

### 3.1 Wu 등, Energy 2021: 비용 비율로 비대칭 벌점 결정

- 논문: *Support vector regression with asymmetric loss for optimal electric load forecasting*. DOI: [10.1016/j.energy.2021.119969](https://doi.org/10.1016/j.energy.2021.119969).
- 확인 본문: [저자 원고 전문](https://www.researchgate.net/publication/349183927_Support_vector_regression_with_asymmetric_loss_for_optimal_electric_load_forecasting), §2.1\~2.2, §3.3\~3.4. 기관 저장소 PDF는 브라우저에서 본문 접근이 되지 않아 저자 원고 본문을 확인했다.
- 방식: 과대예측 비용 k_over와 과소예측 비용 k_under를 달리 둔 선형-선형 손실. ε 이내의 작은 오차를 제외하는 변형도 사용.
- 설정: A$/MWh 기준 과대 80 / 과소 600 및 과대 80 / 과소 900의 두 비용 시나리오. 비율은 각각 **7.5, 11.25**.
- 선정: 비용 시나리오에서 비율을 정하고, SVR 정규화·ε는 교차검증으로 선택한다. 비용 비율을 정확도만으로 임의 선정한 것과 구분한다.
- 적용 판단: 우리 공장의 실제 과소·과대 오차 비용을 알면 가장 설명하기 좋은 근거다. 이 시나리오 단가·비율을 한국 공장에 복사하거나 L_peak의 제곱오차 가중치로 바로 쓰지는 않는다.

### 3.2 Lin 등, Energies 2020: 계약전력 요금표에서 손실 직접 유도

- 논문: *Asymmetric Loss Functions for Contract Capacity Optimization*. DOI: 10.3390/en13123123.
- 확인 본문: [출판사 PDF](https://mdpi-res.com/d_attachment/energies/energies-13-03123/article_deploy/energies-13-03123.pdf), §3\~4, 식 (1)\~(4).
- 방식: 대만 전력의 월별 계약전력 요금 구조를 손실에 반영. 초과분 중 계약의 10% 이내는 기본 요율의 2배, 그 이상은 3배인 구조를 사용.
- 원래 비용에서 정상적인 최소 비용을 뺀 penalty는 다음과 같다. y는 월 실제 수요, p는 계약 용량 예측이다.

      P(y,p) = p−y                    if y ≤ p
               y−p                    if p < y ≤ 1.1p
               2y−2.1p                if y > 1.1p

- 선정: 임의의 peak weight 대신 요금 규칙에서 손실을 유도한다. 요율 2배·3배를 단순 과소예측 가중치 2·3으로 읽으면 위 식과 달라진다.
- 적용 판단: 계약전력 비용을 줄이는 의사결정에는 적합한 접근이다. 연구의 대만 요금을 현재 한국 공장의 규칙으로 전제하지 않는다. 15분 경로 예측과 월 최대 계약 결정의 관측 단위도 다르다.

### 3.3 Zhang·Wang·Hug, EPSR 2022: 운용 시뮬레이션으로 오차-비용 함수 생성

- 논문: *Cost-Oriented Load Forecasting*. DOI: 10.1016/j.epsr.2021.107723. 2021 사전원고와 2022 출판을 구분한다.
- 확인 본문: [저자 arXiv PDF](https://arxiv.org/pdf/2107.01861), §II\~III. [출판사 정보](https://www.sciencedirect.com/science/article/pii/S0378779621007045).
- 방식: 여러 예측 오차 시나리오를 경제급전·불균형 정산·배터리 운용에 넣어 실제 비용을 생성한다. 이를 spline과 구간 선형 함수로 근사하고 경계를 매끄럽게 연결해 학습 손실로 사용한다.
- 선정: 구간별 벌점 크기를 비용 시뮬레이션에서 얻는다. 하나의 보편적인 peak 가중치 숫자를 제안하는 연구가 아니다.
- 적용 판단: 운영 비용·제약을 모델링할 수 있을 때의 확장 방향이다. 현재 데이터만으로 같은 비용 함수를 계산했다고 주장할 수 없다.

### 3.4 Jurasovic 등, AUPEC 2018: 실제 부하 크기의 세제곱 가중

- 논문: *Day Ahead Load Forecasting for the Modern Distribution Network – A Tasmanian Case Study*. DOI: 10.1109/AUPEC.2018.8758023.
- 확인 본문: [저자 대학 PDF](https://users.cecs.anu.edu.au/~pscott/extras/papers/jurasovic2018.pdf), 식 (5) 및 Table I. [대학의 출판 정보](https://researchportalplus.anu.edu.au/en/publications/day-ahead-load-forecasting-for-the-modern-distribution-network-a-/).
- 방식: Σ_t (prediction_t−actual_t)² × |actual_t|^c. 실제 부하가 큰 시점의 제곱오차를 더 강조한다.
- 설정: 사례 연구의 **c=3**를 Table I에서 확인했다. c의 폭넓은 탐색이나 보편적 최적성은 확인되지 않았다.
- 적용 판단: RF의 예측 확률 없이 실제 목표 크기로 피크를 강조하는 선행 사례다. 대상은 배전 부하·kVA이고 손실의 스케일과 전처리가 다르다. 우리 kW 값을 그대로 세제곱하면 큰 값·이상치 영향과 다른 C 항의 상대 스케일이 크게 달라지므로 직접 채택하지 않는다.

### 3.5 Wang 등, IEEE TSG 2023: 검증 성능에 따라 표본 가중치 학습

- 논문: *Improving Load Forecasting Performance via Sample Reweighting*. DOI: 10.1109/TSG.2023.3269205.
- 확인 본문: [저자가 공개한 원고 전문](https://www.researchgate.net/publication/370129081_Improving_Load_Forecasting_Performance_via_Sample_Reweighting), §II 및 Algorithm 1. [기관 서지·초록](https://hub.hku.hk/handle/10722/339052).
- 방식: 가중 학습 손실로 모델을 적합하는 내부 최적화와 검증 손실을 줄이도록 w를 조정하는 외부 최적화. gradient·influence function을 이용한다.
- 선정: 표본마다 고정된 2배를 주는 방식이 아니라 **검증 목적에 도움이 되는 방향으로 학습**한다.
- 적용 판단: 가중치도 검증해야 한다는 근거다. 논문은 gradient 기반 모델을 대상으로 하며, 현재 기저 트리 학습기에 동일 절차를 붙였다고 할 수 없다. 전체 데이터의 개별 w 학습은 첫 실험 범위보다 비용·복잡도가 커 우선순위를 낮춘다.

### 3.6 Hari 등, APAL 2026: 과소 벌점·피크 가중치를 분리하여 검증 탐색

- 논문: *Asymmetric Peak-Aware Loss for Peak-Critical Time Series Forecasting*.
- 상태: **2026-07-16 arXiv 사전원고**. 공개 페이지에서 정식 게재·동료평가 상태를 확인하지 못했다.
- 확인 본문: [원문 §3.3, Appendix E](https://arxiv.org/html/2607.14871v1).
- 방식: MAE에 `1+(λ_u−1)I[prediction<y]`와 `1+(λ_p−1)I[y≥τ×경로 내 실제 최댓값]`을 곱한다. λ_u는 과소 벌점, λ_p는 피크 중요도다.
- 탐색: 기본 grid λ_u·λ_p∈{1,2,5,10}, τ∈{0.8,0.9,0.95}; Beach 자료는 가중치 15·20까지 확대. 선정은 검증셋으로 한다.
- 제안 초기값: **(λ_u, λ_p, τ)=(2,2,0.9)**. 이는 모든 자료의 최적값이라는 뜻이 아니다.
- 적용 판단: 두 가중치의 효과를 분리하는 방식과 탐색 후보의 근거로 참고한다. 원 손실은 MAE이고, threshold는 B가 아닌 경로의 실제 최대이며, 주요 대상은 보행 수요다. 현재 C에 옮기면 별도 변형이고 검증이 필요하다.

## 4. 현재 프로젝트에 대한 판단

### 4.1 RF 확률 결합을 기본값으로 삼을 근거는 부족하다

검토한 원문들은 비용·실제 목표 크기·피크 여부·검증 영향도를 이용한다. 동일한 `(1+p_RF)/2` 결합식은 확인하지 못했다. 특히 RF가 예측하지 못한 실제 피크는 추가 가중치가 작아진다. 가중치가 1 미만이 되지는 않지만, 실제 피크를 놓치는 문제를 다룰 때 이 결합이 유리한지 별도로 검증해야 한다.

현재 원고의 작동 설명은 설계 의도이며 효과 검증이 아니다. 기존 식은 역사적 기준으로 보존하고, 연구로 입증된 기본값이라고 표현하지 않는다.

### 4.2 비용을 알 수 있으면 비용 근거를 우선한다

실제로 놓친 피크의 초과요금·운영 손실과 과대예측에 따른 불필요한 조치 비용을 정의한다. 단가만 있으면 충분한 것은 아니다. 지속시간, 월 최대값, 알림의 반복 억제 및 조치 규모를 반영해야 실제 비용을 계산할 수 있다. 이런 정보가 없으면 비용 비율을 만들어 넣지 않는다.

비용 근거가 확보되어도 현재 C의 norm 계수·w를 비용 비율과 등치시키지 않는다. 비용 손실을 새로운 목적·보조 지표로 설계할지 먼저 판단해야 한다.

### 4.3 비용이 없는 현재 단계에서는 단순한 표본 가중치를 검증한다

먼저 **w=1인 전체 C**로 L_peak의 비대칭성 자체가 작동하는지 확인한다. 이후 표본 가중치만 바꿔 비교한다. 방향 벌점과 피크 표본 중요도를 동시에 늘려 원인을 섞지 않는다.

| 제안 비교 | 의미 | 근거·주의 |
|---|---|---|
| W0: w=1 | 추가 표본 가중치 없이 전체 C 직접 학습 | 필수 기준. L_peak는 남는다. |
| W1: 실제 피크 마스크만 사용 | w=1+(λ_p−1)I[y≥τB_o] | λ_p∈{2,5}, 최초 τ=0.9를 작은 후보로 제안. APAL의 탐색 방식을 참고하되 실제 최대 대신 업무 기준 B를 사용하는 **프로젝트 변형**이다. |
| W2: 기존 실제값 ramp, RF 인자 제거 | w=1+(cap−1)g(y/B) | 기존 W_RF와 같은 g·cap를 두면 RF 인자의 효과를 분리할 수 있다. 이 ramp 자체도 맞춤 가정이며 표준식은 아니다. |
| W_RF: 기존 RF 결합식 | w=1+(cap−1)g(y/B)(1+p_RF)/2 | 기존 방식의 기여를 확인하는 추가 비교군. 기본 추천값으로 가정하지 않음. |

λ_p=2·5, τ=0.9는 **문헌에 존재하는 소수 후보를 검증하는 출발점**이다. 현재 C에서 효과가 입증된 설정이 아니다. 5·10처럼 강한 강조를 무조건 확대하지 않고 평균 오차·과대예측·실제 경보 오탐까지 확인한다.

W1과 W_RF는 mask/ramp 및 확률 인자가 함께 다르다. 두 결과의 차이를 RF 인자만의 효과로 해석하지 않는다. RF 인자만의 효과는 W2/W_RF 짝 비교에서 확인한다.

C의 외부 계수 0.5/0.3/0.2와 tail 20%도 이 여섯 논문이 현재 공장에 대해 입증한 값이 아니다. 가중치 검토와 별개이며 첫 목적 변경 비교에서는 고정해야 효과를 구분할 수 있다.

## 5. 선정·평가 시 지킬 조건

- 학습 가중치 후보만 바꾼다. 데이터·원점·F·트리 설정·C 계수·실행 예산은 짝 비교에서 동일하게 둔다.
- 후보별 자신의 가중치로 계산한 C의 최소값을 비교해 가중치를 선정하지 않는다. cap가 작을수록 그 자체로 peak norm이 작아지는 문제가 있다.
- 공통 평가 기준을 먼저 고정하고 모든 후보에 같은 기준을 적용한다. 기존 common cap2 C와 w1 C·과소/과대 오차를 함께 보고하는 것이 가능하다. 대표 선정 기준을 바꾸려면 기존 설계와 다른 제안임을 명시한다.
- 4\~8월 시간순 5-fold에서 선택한다. **8월은 다섯 번째 개발·검증 fold**이고 9월은 설정 동결 뒤 기지 데이터 재평가만 한다.
- 통계적 피크 threshold를 따로 추정한다면 각 학습 구간에서만 추정한다. 기존 초기 B=170의 전체 자료 q90·9월 포함 한계는 그대로 기록한다.
- 학습 정답의 크기·경로 최대를 학습 손실의 중요도 계산에 쓰는 것과 예측 입력에 미래 정답을 넣는 것은 구분한다. 검증 정답이 학습 weight에 섞이지 않도록 한다.
- 회귀 피크 가중치와 사건 분류의 class_weight를 혼동하지 않는다. 회귀 C 변경만으로 피크 확률 보정이나 경보 개선을 주장하지 않는다.
- 평균 오차와 고부하 과소예측·과대예측, 피크 시각·표본 수·달별 변동을 함께 확인한다. 보정된 전력·생산 데이터 영향은 별도로 보고한다.

## 6. 확인 범위와 남은 검증

원문 수식·설정·선정 설명을 확인한 범위는 각 논문 항목에 표시했다. Wu/Wang은 저자 공개 원고 본문을 이용했고, Lin/Jurasovic/Zhang은 출판사 또는 저자 PDF, APAL은 arXiv 원문을 확인했다. 본문 접근이 실패한 일부 추가 검색 후보는 근거 목록에 포함하지 않았다.

현재 확정할 수 있는 것은 **가중치를 정하는 근거와 탐색 절차**다. 우리 데이터에서의 최적 cap·threshold·RF 인자의 유효성은 아직 새 실험으로 검증하지 않았다. 이번 조사로 기존 학습 결과나 파일을 덮어쓰지 않았다.
