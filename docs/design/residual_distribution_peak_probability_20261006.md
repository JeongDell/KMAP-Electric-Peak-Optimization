## 1. 기존 설계와 현재 구현의 관계

[기존 설계서](<loss function.md>)는 미래 전력의 분포·분위수와 미래 경로를 이용해 피크 위험을 계산하는 방향이다. RF 전용 설계는 아니며 부스팅도 분포 추정 단계를 추가해 이 방향을 따를 수 있다.

| 구분 | 현재 RF | 현재 부스팅 | RF·부스팅 공통 신규 계층 |
| --- | --- | --- | --- |
| 전력 예측 | 기존 C 학습 RF | 기존 C 학습 부스팅 | 각자의 기존 C 전력 모델 재사용 |
| 확률 산출 | RF 잎에 속한 실제 학습 경로의 조건부 경험분포 | 시점·기간 초과 여부를 별도 분류기로 직접 학습 | 검증 예측 오차의 경로 분포를 전력 예측에 더한 뒤 계산 |
| 추가 학습·추정 | 경로 분포 구성, 필요 시 확률 보정 | 분류기와 확률 보정 | 오차 수집·분포 추정, 필요 시 확률 보정 |

RF의 기존 분포는 **실제 전력 경로의 분포**이고, 아래 공통 설계는 **각 모델의 기존 예측에 더할 오차 경로의 분포**다. 둘 다 전력 분포에서 초과확률을 계산하지만 분포를 구성하는 방법은 다르다. 현재 부스팅의 직접 분류기 확률을 보정하는 것만으로 전력 분포가 만들어지지는 않는다. 기존 두 방식의 모델·결과는 보존하고 신규 잔차 방식과 비교한다.

## 2. 값과 사건의 정의

| 기호 | 의미 |
| --- | --- |
| \(t\) | 예측을 발행하는 원점 |
| \(h=1,\ldots,H\) | 미래 15분 단위 예측 시점 |
| \(\hat Y_{t,h}\) | 기존 부스팅이 원점에서 예측한 미래 전력, kW |
| \(Y_{t+h}\) | 이후 관측된 실제 전력, kW |
| \(e_{t,h}\) | 실제 전력 − 당시 미래 전력 예측값, kW |
| \(B_t\) | 원점에서 적용하는 피크 초과 기준, kW |

현재 프로젝트 기준은 다음과 같다.

\[
B_t=\max\left(170\text{ kW},\ \text{이번 달 원점까지 관측이 완료된 최대전력}\right).
\]

월이 바뀌면 이전 달 기록을 제외하고 170kW부터 시작한다. 한 원점에서 발행한 전체 미래 경로에는 같은 \(B_t\)를 적용한다. 사건은 엄격한 \(Y_{t+h}>B_t\)이며 같은 값은 초과가 아니다. 170kW는 전체 데이터 q90에 근거한 사용자 지정 초기값으로, 독립 테스트에서 정한 값은 아니다.

잔차를 더하는 출발점은 **현재 측정 전력**이 아니라 **기존 모델의 미래 전력 예측값**이다. 이후 관측값을 경로 중간의 입력이나 B 갱신에 사용하지 않는다.

## 3. 예측 오차를 모아 분포 만들기

### 3.1 시간순 검증 예측으로 오차 수집

\[
e_{t,h}=Y_{t+h}-\hat Y_{t,h}.
\]

예를 들어 1\~5월로 학습해 6월을 예측하고, 6월의 실제값이 관측된 뒤 오차를 저장한다. 이는 설명용 분할 예시이며 새 실험을 실행했다는 뜻은 아니다.

여기서 ‘잔차’라고 부르는 자료는 엄밀히는 **학습에 사용하지 않은 미래 구간의 예측 오차**다. 학습 데이터에 대한 잔차와 구분해야 한다. [예측 오차와 잔차의 구분](https://otexts.com/fpp3/accuracy.html#forecast-errors).

원점별로 다음 정보를 대응시켜 보관한다.

- 원점, 목표 시점·lead, 모델 버전·학습 종료 시각.
- 당시 미래 전력 예측값, 이후 실제값, 오차, 정답 복구 여부.
- 당시 알 수 있었던 예측 전력 수준·시간대·생산 계획 등의 조건.
- 기간 확률을 위한 완전한 H개 오차 벡터 \(\mathbf e_i=(e_{i,1},\ldots,e_{i,H})\).

동일한 예측 구간·해상도·모델 구성의 오차를 사용한다. 서로 다른 부스팅 모델의 오차를 임의로 섞지 않는다. 원점·목표 시점으로 대응을 확인하고, 불완전 경로의 제외 건수를 기록한다. 누락 오차를 0으로 채우지 않는다.

### 3.2 경험분포 구성

가장 단순한 방법은 이용 가능한 과거 오차 경로 N개에 각각 \(1/N\)의 질량을 주는 것이다. 이 경우 새 트리 학습 없이 오차 표를 저장해 경험분포로 사용할 수 있다.

오차가 예측 전력 수준·시간대·생산 상태에 따라 달라지는지 검증한 뒤, 표본이 충분하면 비슷한 조건의 오차 경로를 선택하거나 가중할 수 있다. 조건별 분포의 구분 기준과 최소 표본 수는 아직 확정하지 않았다. 조건은 원점에서 알 수 있는 정보로 정하며 미래 실제 전력이나 미래 초과 여부로 선택하지 않는다.

정규분포나 평균 0을 미리 강제하지 않는다. 특히 C 손실로 학습한 점 예측은 분포의 평균·중앙값과 같다고 가정할 수 없다. 새 분포의 평균이나 Q50이 기존 C 점 예측과 달라도 각각의 역할을 구분해 보고한다.

이 방법은 **현재 조건의 미래 예측 오차가 선택한 과거 오차 경로와 비슷하다는 가정**을 둔다. 조건·계절·모델 학습 범위가 달라졌을 때도 성립하는지는 새 기간에서 확인해야 한다.

## 4. 분포에서 확률 직접 계산

현재 예측 경로에 과거 오차 경로 i를 더해 가능한 미래 전력 경로를 구성한다.

\[
Y^{(i)}_{t,h}=\hat Y_{t,h}+e_{i,h}.
\]

선택한 경로의 질량을 \(a_i\ge0,\ \sum_i a_i=1\)로 두면 시점 초과확률은 다음과 같다.

\[
p_{t,h}=\sum_i a_i\,\mathbf1\left[Y^{(i)}_{t,h}>B_t\right]
=1-G_{t,h}\left(B_t-\hat Y_{t,h}\right),
\]

여기서 \(G_{t,h}\)는 해당 조건에서 선택한 오차 분포의 CDF다. 균등 질량이면 초과한 경로 수를 전체 경로 수로 나눈 값이다.

기간 중 한 번이라도 초과할 확률은 다음과 같다.

\[
p_{t,\mathrm{any}}=\sum_i a_i\,\mathbf1\left[\max_{h=1,\ldots,H}Y^{(i)}_{t,h}>B_t\right].
\]

**시점·기간 확률은 같은 오차 경로와 같은 경로 질량을 사용한다.** 각 시점의 오차를 따로 섞어 독립 경로를 만드는 방식이나 \(1-\prod_h(1-p_{t,h})\)를 사용하지 않는다. 같은 전력 경로 분포에서 분위수·예측범위도 계산할 수 있다.

같은 예측 경로와 오차 분포를 고정하면 B를 높일수록 초과확률은 비증가한다. 이는 비교 기준만 바꾸는 조회이며, 다음 원점에서 새 관측 정보로 예측과 오차 분포를 갱신하는 것과 구분한다.

### 설명용 예시

현재 측정 전력이 160kW, 1시간 뒤 예측이 170kW, B가 180kW라고 하자. 아래 값은 실제 실험 결과가 아니다.

| 과거 예측 오차, kW | 가능한 미래 전력, kW | B 초과 |
| ---: | ---: | --- |
| -10 | 160 | 아니오 |
| -4 | 166 | 아니오 |
| +2 | 172 | 아니오 |
| +8 | 178 | 아니오 |
| +15 | 185 | 예 |

균등 질량이면 \(P(Y>180)=P(e>10)=1/5=20\%\)다. 현재 측정값 160에 오차를 더한 결과가 아니다. 기존 미래 예측 170과 예측의 불확실성을 함께 반영한 값이다.

## 5. 경로 시뮬레이션과 직접 계산의 관계

시뮬레이션은 위와 **같은 경로 분포**에서 경로 ID를 질량 \(a_i\)에 따라 추출하고, 그 오차 벡터 전체를 현재 예측 경로에 더한다. 예를 들어 1시간 경로라면 `[15분, 30분, 45분, 60분]` 오차를 한 묶음으로 추출한다. 이는 과거 경로 안의 시간 의존성을 보존하려는 이 프로젝트의 제안이다.

과거 오차를 재표본추출해 예측에 더하는 기본 원리는 [잔차 기반 미래 시뮬레이션 설명](https://otexts.com/fpp3/prediction-intervals.html#prediction-intervals-from-bootstrapped-residuals)에 근거한다. 여기서는 시점별 독립 추출 대신 완전한 다중 시점 오차 벡터를 사용한다.

| 구분 | 직접 계산 | 시뮬레이션 |
| --- | --- | --- |
| 사용하는 분포 | 선택한 과거 오차 경로의 경험분포 | 같은 경험분포 |
| 계산 | 모든 경로의 초과 여부에 질량을 곱해 합산 | 경로를 반복 추출해 초과한 비율 계산 |
| 결과의 성격 | 구성한 유한 경험분포에 대한 정확한 합 | 그 합의 Monte Carlo 근사 |
| 주 용도 | 시점·기간 확률과 분위수 산출 | 가능한 미래 경로의 표시·분석 |

시뮬레이션 횟수가 늘면 같은 분포의 직접 계산 확률에 가까워진다. 전체 경로를 보관했다면 기간 확률도 직접 계산할 수 있으므로, 확률 산출에 시뮬레이션이 필수는 아니다. 1,000개 경로를 추출했다고 새로운 독립 관측 1,000개가 생기거나 미관측 극단 오차에 대한 정보가 추가되는 것은 아니다.

따라서 **예측 오차 분포 방식과 시뮬레이션 방식이라는 별도 모델 두 개가 아니라, 하나의 분포를 사용하는 두 계산 방법**이다.

## 6. 검증과 확률 보정은 별도 단계

검증은 산출한 확률과 분포가 새로운 기간의 실제 전력·피크 사건에 맞는지 확인하는 것이다. 직접 계산이나 시뮬레이션 자체를 검증이라고 부르지 않는다.

- 시점·기간 Brier와 Logloss, 확률대별 실제 초과 빈도·표본 수를 확인한다. 낮은 Brier만으로 보정이 정확하다고 단정하지 않는다. [공식 확률 평가 설명](https://scikit-learn.org/stable/modules/calibration.html).
- 원점·lead·실제값·B·평가 마스크를 맞추고 기존 과거빈도 기준선과 비교한다. 복구된 정답을 포함한 결과와 제외한 결과를 구분한다.
- 분위수 포함률·예측범위 폭과 피크일 수를 함께 보고한다. 중첩 경로와 같은 피크에 대한 반복 발행을 독립 표본으로 세지 않는다.
- 보정이 필요하면 분포 추정과 최종 평가에서 분리된 과거 예측 자료로 적합한다. 확률만 보정하면 분위수·경로 분포까지 함께 보정되는 것은 아니다.

**현재 저장된 부스팅 7·8월 예측은 설정과 트리 수 선정에도 사용됐다.** 이를 오차 분포 학습에 사용하고 같은 기간에서 최종 평가하면 낙관적인 결과가 나올 수 있다. [C 학습 코드](../notebooks/_shared/full_c_boosting.py), [분할·예측 저장 코드](../notebooks/_shared/full_c_tuning.py). 오차 수집·분포 선택·보정·최종 평가의 시간 구간과 역할을 실행 전에 정하고, 각 경로의 마지막 정답이 다음 경계에 닿거나 넘어가면 제외한다.

9월도 초기170 설정과 기존 열람 이력 때문에 독립 테스트가 아닌 탐색 평가다. 미래 생산·날씨 실측을 예보처럼 사용하는 기존 future 조건은 예보 오차0 시나리오이며 실제 운영 예보 검증과 구분한다. 현재 F1/F2 입력 구성과 학습·보정 방식이 RF·부스팅 간 완전히 같지 않으므로 알고리즘 자체의 효과를 분리하려면 공통 입력 조건도 정해야 한다. [기존 결과 분석과 입력 차이](../reports/peak_probability_analysis_20261006T153010_KST/INTERPRETATION.md).

## 7. 재사용 범위와 실행 전에 채울 항목

**RF·부스팅의 기존 전력 모델 전체를 다시 튜닝하는 것이 필수는 아니다.** 각자의 기존 C 전력 모델을 유지하고 공통 분포 계층을 추가할 수 있다. 다만 누수 없이 사용할 과거 검증 예측이 부족하면, 선정된 설정을 고정해 오차 수집용 과거 모델을 일부 추가 학습해야 한다. 기존 저장 예측의 재사용 가능 범위는 별도 확인이 필요하다.

실행 전에 채울 항목은 오차 수집 기간, 별도 조건부 분포 실험의 구분 기준과 최소 표본 수, 분포·보정·평가 분할, 오차 수집용 추가 학습 범위, 시간·메모리 예산이다. 기본 구현과 완료 기준은 아래에 명시한다. 이 문서 작성에서는 기존 모델 교체나 새 실험을 수행하지 않았으며, 잔차 분포의 성능 수치를 제시하지 않는다.

정리한 흐름은 다음과 같다.

**기존 C 전력 예측 유지 → 과거 미래 예측 오차 수집 → 오차 경로 분포 구성 → 확률 직접 계산·경로 시뮬레이션 → 새 기간 검증 → 필요 시 별도 확률 보정**

현재 구현 참고: [RF 분포·확률 API](../notebooks/models/random_forest/rf_peak_model.py) · [부스팅 직접 분류 설계](../notebooks/models/boosting/PEAK_PROBABILITY.md).

최초 공통 비교는 최신 RF 선정 F를 기준으로 `1h:F2, 4h:F2, 8h:F1, 12h:F1, 24h:F1, 4d:F2`의 future 조건을 정렬하고, 같은 F 조건의 세 부스팅을 대응시키는 안이다. 이는 기존 완료 모델을 비교하기 위한 설계이며 새 F 선정이 아니다. 다른 F·시나리오의 확대는 별도 실험으로 기록한다.

## 9. 공통 입력·출력 계약과 모델 어댑터

### 9.1 공통 원점 입력

외부 입력은 `origins`, 과거 관측, 당시 미래 계획·예보, `state_threshold_kw`, 조건 식별자다. 각 C 모델의 어댑터가 저장된 피처 이름·순서·구성을 그대로 생성한다. 미래 실제 전력은 현재 추론 입력에 포함하지 않는다.

공통 출력의 기준 배열은 다음과 같다.

| 필드 | 형태·의미 |
| --- | --- |
| origins | N개 고유 원점, 시간순 |
| target_end | 원점 + 15분 × lead, `(N,H)` |
| predicted_kw | 기존 C 미래 전력 예측, `(N,H)` |
| threshold_kw | 발행 경로 안에서 고정하는 B, `(N,)` |
| residual_paths_kw | 모델별 과거 완전 오차 경로, `(N_pool,H)` |
| residual_origins | 공통 오차 경로 ID를 구성하는 원점 목록 |
| path_weights | 원점별 과거 경로 질량, `(N,N_pool)` 또는 배치 조회 |

현재 데이터 시각이 시간대 정보 없는 값이면 원래 기준을 보존하고 임의로 UTC/KST 변환하지 않는다. `timestamp_time_basis`를 확인해 모델·오차·정답 모두 같은 기준으로 대응한다.

현재 원점의 실제 기준 `state_threshold_kw`와 분석용 `query_threshold_kw`를 구분한다. 기본 조회 B는 실제 기준과 같다. 같은 원점에서 가상의 B를 바꿔 조회할 때는 C 입력과 예측 경로·오차 질량을 고정한다. RF F2처럼 B에서 파생한 기존 피처까지 다시 만들어 다른 예측 상태를 조회하지 않는다.

### 9.2 모델 어댑터

| 어댑터 | 기존 모델에서 가져오는 것 | 공통 계층에 전달 |
| --- | --- | --- |
| RF | C로 적합된 RF의 전력 경로 예측. 현재 API의 `point_forecast`에 해당 | `(N,H)` 전력 경로 |
| 부스팅 | 저장한 CBoosting 모델의 `predict` 전력 경로 | `(N,H)` 전력 경로 |

현재 RF 잎 분포 확률이나 부스팅 분류기 확률을 신규 잔차 계층의 입력 확률로 사용하지 않는다. 두 기존 확률 방식은 별도 비교군이다. 모델 재로딩 전후 전력 예측이 동일한지 확인하고 모델 파일 SHA256·피처 스키마·profile·F·scenario를 검사한다.

### 9.3 공통 확률 출력

- `p_point_raw`: `(N,H)` 시점 초과확률.
- `p_any_raw`: `(N,)` 전체 기간 초과확률.
- `q_raw_kw`: `(N,H,7)`의 Q05/Q10/Q20/Q50/Q80/Q90/Q95.
- `interval90_raw_kw`: Q05\~Q95. 실제 포함률은 평가로 확인한다.
- `sample_paths_raw_kw`: 필요할 때 `(N,M,H)` 생성. M의 기본 설계값은 1,000, seed는 42다.
- `sample_residual_ids`: 생성한 경로의 원래 과거 오차 ID.
- `actual_kw`: 평가 자료에만 저장하고 정답 없는 추론에서는 요구하지 않는다.
- 메타데이터: 모델·분포 버전, 경로 수, 마지막 사용 정답 시각, 질량 방식, B, seed, 출력이 raw인지 여부.

예측 CSV는 `model, profile, feature, scenario, origin, lead_step, target_end, threshold_kw, predicted_kw, actual_kw, p_point_raw, p_any_raw, q05_kw, q50_kw, q95_kw`를 포함한다. `p_any_raw`는 경로 단위 값이므로 lead별 행에 반복해도 별도 독립 관측으로 집계하지 않는다.

## 10. 공통 잔차 분포의 초기 구현

초기 버전은 **균등 경험분포 E0**로 고정한다. 조건부 경로 선택 E1은 효과를 구분할 수 있도록 별도 후속 실험으로 둔다.

1. 모델별 오차 수집 후보에서 완전 H개 목표와 예측이 있는 경로만 남긴다.
2. 실제 정답을 복구·대체한 경로는 초기 오차 풀에서 제외한다. 실제 예측 오차로 해석할 수 없기 때문이다. C 모델의 기존 학습이나 full 평가 대상을 변경한다는 뜻은 아니다.
3. RF와 세 부스팅의 적격 과거 원점 교집합을 사용한다. 실제 목표·lead·정답 마스크가 일치하는지 검사한다. 모델별 제외 사유와 교집합 손실 건수를 저장한다.
4. 같은 순서의 실제 경로에서 각 모델의 예측 경로를 빼서 모델별 오차 행렬을 만든다. 질량은 모든 모델에서 동일한 `1/N_pool`다. C의 피크 가중치를 경로 질량에 복사하지 않는다.
5. 현재 전력 예측에 오차 벡터를 더하고 4절의 합산으로 확률과 가중 이산 분위수를 계산한다.
6. 같은 경로 질량과 seed로 시뮬레이션한다. E0에서는 모델 간 동일한 경로 ID를 추출해 비교할 수 있다.

오차 풀이 비어 있으면 계산을 실패로 기록한다. 균등분포가 ‘모든 조건에서 오차가 동일하다’는 좋은 모형이라고 가정하지 않으며, 표본 수와 조건별 오차를 평가한 뒤 E1 확대 여부를 판단한다.

E1은 같은 원점에서 알 수 있는 공통 조건으로 경로를 선택·가중하고, 하나의 원점에는 전체 H에 공통인 경로 질량을 사용한다. 시점마다 다른 질량을 사용하는 주변분포들을 그대로 기간 분포라고 취급하지 않는다. 조건 구분·학습하는 경계값·최소 표본·부족 시 E0로 돌아가는 규칙은 검증 전 설정에 기록한다.

경험 오차를 다른 예측 수준에 더하면 원시 경로에 음수가 나타날 수 있다. 초기 분석은 원시 합산값과 음수 발생 건수를 기록한다. 임의 절단으로 분포를 바꾸지 않으며, 물리적 하한 처리의 채택은 별도 명시된 비교로 판단한다.

## 11. 시간순 분할·모델 재사용·보정

### 11.1 기간 역할

| 구간 역할 | 허용 작업 | 다음 단계와의 관계 |
| --- | --- | --- |
| C 학습·내부 검증·선정 | 전력 모델 학습, 설정·트리 수 선정 | 오차 수집용 모델에서 사용한 정답 범위 기록 |
| R: 오차 수집 | 당시 알 수 있는 정보로 미래 전력 예측, 관측 후 오차 저장 | 평가 원점보다 전체 오차 경로의 목표가 먼저 종료 |
| D: 분포 설정 검증 | E0/E1 등 사전에 정의한 후보 비교 | 최종 평가 전에 구성 동결 |
| K: 선택적 보정 | 동결한 원시확률을 별도 과거 정답으로 보정 | 최종 평가 정답을 사용하지 않음 |
| E: 최종 평가 | 동결한 모형을 실제 사건과 비교 | 설정·보정·후보 재선정에 사용하지 않음 |

구간 역할은 원칙이고 구체적인 날짜는 아직 확정하지 않았다. 원점·목표 중첩을 검사해 각 구간의 완전 경로 마지막 목표가 다음 경계보다 엄격히 이전인 자료만 사용한다. 자료가 부족하면 D/K 생략과 raw E0 평가 등으로 범위를 명시하며 같은 정답을 여러 역할에 숨겨 사용하지 않는다.

### 11.2 재사용 가능성 검사

저장된 예측마다 `fit_target_end`, `selection_target_end`, 예측 시점, source/model/schema 해시를 확인한다. 예측 대상의 정답이 C 적합·설정 선정·early stopping에 쓰였는지 구분한다. 엄격한 평가에 부적격한 기존 7·8월 출력은 개발 참고 자료로 표시하며, 독립 검증 오차처럼 취급하지 않는다.

재사용 자료가 충분하면 기존 전력 모델을 새로 학습하지 않고 오차 분포만 구성한다. 부족하면 C의 확정 설정을 이용해 과거 시점별 학습·예측을 재현한다. 부스팅의 외부 평가 정답으로 트리 수를 다시 고르지 않고, 그 원점 이전 내부 자료에서 정한 트리 수를 사용한다. 이 추가 적합은 **오차 수집 목적**이며 전체 그리드 재탐색과 구분한다.

현재 채택 설정을 과거 시점에 소급해 사용하는 자료는 당시 설정 선정 정보까지 이용 가능했는지 별도로 검사한다. 성립하지 않으면 회고적 개발 실험으로 표시한다. 기존 전체q90·9월 열람 이력까지 고려하면, 현재 데이터만으로 새 독립 테스트가 확보됐다고 보고할 수 없다.

모델의 학습 범위가 다른 여러 과거 cutoff 오차를 합칠 때는 동일한 학습 절차·설정·스키마의 `base_recipe_id`와 개별 모델 SHA를 기록한다. 이런 오차 분포가 현재 적합 객체에도 적용되는지는 평가로 확인한다. 기존 C 모델이 새로 재학습되면 오차 분포의 연결 버전을 갱신하고 재검증한다. 자동 재학습 주기는 이 문서에서 새로 설정하지 않는다.

### 11.3 확률 보정

두 계열 모두 기본 주 출력은 같은 원시 경로 분포의 `raw` 확률이다. 기존 RF나 분류기에 적합한 보정함수를 신규 잔차 확률에 그대로 재사용하지 않는다.

보정 실험을 한다면 동일한 K 구간·동일 사건·동일 함수 계열을 사용한다. 시점·기간 확률 보정과 일관성 범위 투영을 적용해도 보정된 결합 전력 분포를 학습한 것은 아니다. `q_raw_kw`, `sample_paths_raw_kw`와 `p_calibrated`를 분리하고 `calibrated_joint_distribution=false`를 저장한다. 원시분포와 보정출력의 채택 여부는 사전 검증 기준으로 판단한다.

## 12. 비교와 평가 기준

확률 계산 코드와 오차 풀 원점·질량·B·평가 원점을 동일하게 맞춘다. 오차값은 각 C 모델의 전력 예측에서 계산하므로 모델별로 다르다.

**기존 C 모델 재사용 비교는 확률 계층을 공통화한 완성 모형 비교다.** RF·부스팅의 기존 F 피처 열·미래 입력 표현·학습 절차까지 자동으로 같아지는 것은 아니다. ‘알고리즘 하나만 다른 비교’가 필요하면 C 입력·학습 기간·선정 절차도 맞춘 별도 실험이 필요하며, 저장 모델 스키마가 달라지면 해당 전력 모델의 신규 적합이 필요할 수 있다.

새 잔차 방식은 공통 원점에서 기존 RF 잎 분포·부스팅 직접 분류와 비교한다. 기존의 저장 점수를 다른 평가 원점에 그대로 가져와 비교하지 않고, 같은 원점·사건·정답 마스크로 점수를 계산한다.

- 주 지표: `0.5 × 시점 Brier + 0.5 × 기간 Brier`. 월별 검증을 쓰면 현재 관례대로 월별 동일 평균을 사용한다.
- 보조 지표: Logloss, 확률 보정 표, AP, Q05\~Q95 Pinball·포함률, 90% 구간 폭.
- 조건별: 예측 lead·시간대·요일·생산 상태·B까지의 예측 거리와 표본 수. 부적격·누락 경로 수를 함께 보고한다.
- 기준선: 공통 과거 실제 전력 경로에 현재 B를 적용한 시점·기간 초과빈도 및 항상0확률. 잔차 방법과 동일한 대상에서 평가한다.
- 경보: 고정 tau별 누락·오경보·발행 수를 진단한다. 기존 정책과 구분하고 업무 비용 없이 운영 tau를 새로 확정하지 않는다.
- 정답 처리: 기존 full 점수를 주 평가로 유지하고 `clean_targets` 민감도를 함께 보고한다. 오차 풀의 실제 정답 적격성 처리와 평가 대상은 구분한다.

아직 새 잔차 방식의 성능·자원 사용량을 측정하지 않았다. 원시확률의 구조적 일관성과 좋은 확률 성능은 별개다.

## 13. 구현 인터페이스와 검증 항목

다음은 신규 공통 모듈의 **계획 인터페이스**다. 현재 실행 가능한 API나 구현 코드가 아니다. 공통 위치 후보는 `notebooks/_shared/residual_peak_distribution.py`이며 어댑터와 실행 기록은 기존 RF·부스팅 폴더 관례를 따른다.

```python
# 계획 인터페이스
adapter.predict_point(origin_inputs) -> predicted_kw[N, H]
collector.collect_verified_forecasts(...) -> residual_paths_kw[N_pool, H]
distribution.fit(residual_paths_kw, residual_keys, metadata)
distribution.predict(predicted_kw, query_threshold_kw, origin_context)
# 반환: p_point_raw, p_any_raw, q_raw_kw, interval90_raw_kw, metadata
distribution.sample_paths(predicted_kw, origin_context, n_paths=1000, seed=42)
# 반환: sample_paths_raw_kw, sample_residual_ids
```

설정에 모델 버전·profile·F·scenario, 데이터·코드 해시, 시간대 기준, 각 구간 역할·날짜, 잔차 적격성, E0/E1, seed·M, 보정·평가 지표, 추가 적합 횟수·시간·메모리 상한을 기록한다. 전력 모델 해시가 바뀌거나 입력 열·순서·H·원점 키가 맞지 않으면 묵시적으로 계속하지 않는다.

최소 검증은 다음과 같다.

1. 원점·lead 키 유일성, `(N,H)` 정렬, 유한값, 질량 비음수·합1, 모델·데이터 해시.
2. 현재 미래 실제 전력을 가려도 C 예측·B·확률·표본 경로가 같음.
3. 같은 원시분포에서 `max(p_h) ≤ p_any ≤ min(1,sum(p_h))` 성립.
4. 같은 예측·오차 질량을 고정하고 B를 올리면 확률 비증가. 같은 경로의 prefix 기간 확률은 구간을 늘리면 비감소. 서로 다른 profile 모델 간 단조성은 보장하지 않음.
5. 원시 분위수 순서와 직접 계산의 재현성. 시뮬레이션은 같은 seed의 재현성과 Monte Carlo 오차 범위를 검사하며 직접 계산과 기계적으로 완전 일치를 요구하지 않음.
6. 재로딩 후 기존 C 전력 출력 및 신규 확률·분위수가 수치 허용오차 안에서 같음.
7. 오차 수집·분포·보정·평가 경계 누수와 설정 선정 정보 시점 검사. 부적격 과거 오차를 허용하는 개발 실행은 명시적으로 표시.

### 수식 검증용 작은 예시

설명용 `예측=[170,175]`, `B=180`, 동일 질량의 오차 경로 세 개를 사용한다.

| 오차 경로 | 가능한 전력 경로 | 시점 초과 | 기간 초과 |
| --- | --- | --- | --- |
| [0,0] | [170,175] | [0,0] | 0 |
| [15,0] | [185,175] | [1,0] | 1 |
| [0,10] | [170,185] | [0,1] | 1 |

직접 합산은 `p_point=[1/3,1/3]`, `p_any=2/3`다. 시점 독립성을 가정한 값 `1-(2/3)^2=5/9`와 다르다. 따라서 시점 확률만 곱해 기간 확률을 만들면 이 경험분포와 맞지 않는다. 작은 예시의 계산 검증은 실제 데이터 모델 성능 평가와 구분한다.

## 14. 실행 단계와 기록·완료 기준

1. 공통 대상·분할·예산과 저장 모델의 재사용 적격성을 확정한다. 계획을 먼저 기록한다.
2. 소규모 키·스키마 검사 후 적격 오차를 수집한다. 필요한 C 추가 적합만 실행하고 버전·횟수·시간을 남긴다.
3. RF·세 부스팅의 공통 E0 분포를 구성하고 수식·추론·재로딩을 검증한다. 직접 계산과 시뮬레이션은 한 모형의 기능 검증이며 별도 예측 후보 두 개로 세지 않는다.
4. 동결 조건으로 평가하고 기존 확률 방식·기준선과 비교한다. E1·보정 등 변경은 별도 후보로 기록한다.
5. 모델별 실험 기록·비교 인덱스와 최종 보관을 확인한 뒤 결과를 보고한다.

모델별 개별 실험은 `experiments/<model_name>/<run_id>/records/<experiment_id>.md`에 남긴다. 오차 수집용 C 적합도 모델·분할·설정이 다른 실행이면 개별 기록을 남기고 분포 실험에서 연결한다. 같은 예측을 단순 재조회·재표본한 것을 새 C 학습으로 기록하지 않는다.

완료 묶음은 `final/<model_name>/<run_id>/`의 `code/`, `records/`, `model/`, `results/`, `README.md`에 보관한다. 공통 구현 코드의 정확한 버전, 기존 C 모델 참조·해시, 모델별 오차 경로·원점 ID·적격성, 입력 스키마·분포·보정 설정, 예측·평가·표·그래프·검증 로그를 연결한다. 기존 완료 묶음을 덮어쓰지 않는다.

완료 보고의 필수 항목은 **기존 C 모델 변경 여부, 추가 C 적합·확률 보정 횟수, 잔차 경로 수와 제외 사유, 공통 비교 가능 범위, 실제 지표, 누수·독립 평가 여부, 최종 묶음과 보고서 경로**다. 모든 단계가 실패하면 후보 미선정을 기록하고 결과나 모델을 만들어 넣지 않는다.

문서 작성 검토: 설명용 시점·기간 확률 예시의 직접 합산과 동일 분포의 표본추출을 계산해 확인했다. 로컬 참조 경로·마크다운 코드 블록과 전처리 데이터 해시를 확인했다. 이는 문서·수식 검토이며 신규 모델 실험이나 성능 검증이 아니다.
