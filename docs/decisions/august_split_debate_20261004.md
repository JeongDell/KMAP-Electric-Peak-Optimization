## 최종 합의와 적용 범위

**다음 튜닝 실험의 기본 권고는 A: 4\~8월 expanding 5-fold로 모델·피처·파라미터·윈도우를 공동 선정하는 방식이다.** 두 채팅이 상대의 반론을 확인한 뒤 이 권고에 동의했다. 이는 설계 판단이며, A가 미래 RMSE를 실제로 개선했다는 검증 결과는 아니다. 기존 B 실행과 동결 평가 결과를 보존하고, 40개 대표 점수를 재평균한 것만으로 모델을 교체하지 않는다.

| 안 | 모델별 설정과 모델 종류의 선정 | 최종 재학습 |
|---|---|---|
| A | 4\~8월의 월별 RMSE를 동일 가중 평균하여 전체 후보 비교 | 선정 후 설정 동결 → 1\~8월 |
| B | 4\~7월에서 모델별 설정 선정 → 8월에서 대표 4개 중 모델 종류 선정 | 선정 후 설정 동결 → 1\~8월 |

양안은 최종 학습 데이터 양이 같다. 5-fold는 무작위 K-fold가 아니라 다음 expanding 분할이다. 각 학습 목표 경로는 검증 시작보다 먼저 끝나야 하며, 검증 목표 경로도 해당 월 안에서 끝나야 한다.

| fold | 학습 | 검증 |
|---|---|---|
| 1 | 1\~3월 | 4월 |
| 2 | 1\~4월 | 5월 |
| 3 | 1\~5월 | 6월 |
| 4 | 1\~6월 | 7월 |
| 5 | 1\~7월 | 8월 |

## 주장과 반론의 교환

1. ‘손실함수 설계서 업데이트 (2)’는 A를 지지했다. 한 달의 모델 순위에 대한 의존을 줄이고, 4\~7월에서 탈락한 설정도 8월을 포함하여 비교할 수 있다는 주장이다. 다월 모델 선택 연구가 이를 뒷받침하지만, 연구가 이 프로젝트의 A/B를 직접 비교한 것은 아니다.
2. ‘부스팅 모델 학습 계획 작성’은 처음에 B를 지지했다. 8월의 1\~7월 학습 모델이 최종 1\~8월 학습 상황과 더 가까우며, A에서 8월의 비중이 20%이면 최근 악화가 이전 달의 이점으로 상쇄될 수 있다는 반론이다.
3. A 측은 최근 성능 희석을 인정했다. 다만 8월의 조건과 모델 순위가 다음 기간에도 이어진다는 근거가 없으면 한 달의 우위를 미래 우위로 해석할 수 없다고 답했다. B가 8월에서 최소 RMSE를 고르는 것은 선택 규칙의 결과다.
4. B 측은 A로 기본 권고를 조정했다. 최근 조건의 지속성이 미확인이고, 모델별 대표 하나로 조기 제한하면 최근에 좋아지는 다른 피처·윈도우·파라미터를 최종 단계에서 되살릴 수 없다는 점을 받아들였다.
5. 양측 공통 예외: 지속적인 생산·운영 변화가 확인되고 최근 모델의 우위가 주별·조건별·보정 민감도에서도 유지되면 B를 우선 검토할 수 있다. 지금 이 조건을 충족했다고 확인한 것은 아니다.

두 채팅에는 내가 상대의 주장과 완료 답변을 전달하여 토론을 중계했다. 새 채팅이나 하위 에이전트를 만들지 않았다.

## 한계와 다음 성능 비교

- A 전체 절차를 실제로 학습·평가하지 않았다. 따라서 ‘A가 B보다 몇 % 개선’이라는 수치는 없다.
- 기존 40개는 4\~7월 결과로 선정된 대표다. 이를 과거의 가상 테스트 비교에 그대로 쓰면 선정 단계의 미래 정보가 섞일 수 있다. 공정한 다음 달 비교에는 공통 후보풀과 탐색 예산을 정하고, 각 과거 평가 월을 제외한 상태에서 선정 절차부터 재현해야 한다.
- 예를 들어 8월을 바깥 평가 월로 두면, A 방식은 4\~7월 통합 선정, B 방식은 4\~6월 설정 선정 뒤 7월 모델 종류 선정으로 재현할 수 있다. 이는 절차를 한 달 앞에서 비교하는 backtest이며 정확히 5개 대 4개의 동일한 fold 수 비교는 아니다. 더 이른 평가 월도 활용하되 초기 학습량과 검증 월 수 차이를 보고해야 한다.
- 9월은 이미 다른 실험에서 결과가 열람되었다. 이번 토론과 재계산에서는 9월 지표를 선정 근거로 사용하지 않았다. 향후 바뀐 설정을 같은 9월에서 평가해 새로운 미열람 최종 테스트라고 부르지 않는다. 강한 외부 검증에는 새 미사용 기간·자료가 필요하다.
- 미래 실측 대체는 사후 생산·기상값을 예보로 취급한 가정이다. 실제 계획·예보 기반 운용 성능으로 확정하지 않는다.
- 기존 분할·모델·실험 인덱스는 변경하지 않았다. 이번 작업은 토론과 기존 결과 재집계이며 개별 모델 실험을 추가하지 않았다.

## 논문·공식 근거와 참조 채팅

- [Cerqueira 등, Model Selection for Time Series Forecasting](https://arxiv.org/html/2104.00584v2): 여러 평가 방법의 모델 선정 능력을 비교한다. 단일 holdout의 한계에 대한 근거이지만, B는 4-fold와 최근 선정의 조합이므로 논문의 단일 holdout과 같다고 취급할 수 없다.
- [Hewamalage 등, Forecast evaluation for data scientists](https://link.springer.com/article/10.1007/s10618-022-00894-5): 비정상성 종류에 따라 평가 방식이 달라지고, 점진적 분포 변화에서 마지막 검증 구간이 적절할 수 있음을 설명한다. 이 프로젝트에서 변화의 지속성을 입증한 것은 아니다.
- [Forecasting: Principles and Practice — Time series cross-validation](https://otexts.com/fpp3/tscv.html): 미래 관측을 학습에 넣지 않는 시간순 평가의 근거.
- [부스팅 모델 학습 계획 작성](thread://01a10096-b07c-7e51-b3a2-b0e75bdcbf6b?hostId=local): 최종 반론 뒤 A로 기본 권고 조정.
- [손실함수 설계서 업데이트 (2)](thread://01a10009-4a8a-7572-ba54-e346994c2024?hostId=local): A 권고 유지 및 최종 합의 확인.
