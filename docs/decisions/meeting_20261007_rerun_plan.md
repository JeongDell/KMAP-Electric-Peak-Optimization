## 8월 마진 검증 판정 방식 (8월 결과 열람 전 기록, 2026-10-07 10:00 KST)

- 모델: 7월에 고른 F·설정·학습방식 그대로 1\~7월(마지막 정답 칸 종료 ≤ 8/1 00:00)로 재학습. 부스팅 나무 수는 8월용 확인 구간(학습 끝 원본 날 14일 = 7/17\~7/31) 최저 round. 대표 = 4모델 단순평균(7월과 같은 구성). 8월로 모델·설정을 고르지 않음.
- 칸 판정(구간별): 맞힐 칸 시작 시각 t의 b(t) = 그 시각 직전까지 이번 달 최고와 170 중 큰 값. 실제 피크 근처 시각 = y(t) ≥ 0.9·b(t).
  발행 원점 o의 예측 칸이 ŷ ≥ (0.9 − m_g)·b_origin(o)이면 t에 경보(m_g = 7월 마진 표의 그 칸 조건 마진, 조건 = 맞힐 시각의 생산량·주간/야간·강수).
- 경보 묶음: 경보가 걸린 시각들을 시간순으로 보고, 묶음 시작 후 60분 안의 경보는 같은 경보 1번으로 센다.
- 헛경보 = 묶음 [시작, 시작+60분) 안에 실제 피크 근처 시각이 하나도 없는 묶음. 하루 헛경보 = 헛경보 묶음 수 ÷ 8월 날 수.
- 피크 근처 날 = 실제 피크 근처 시각이 하나라도 있는 날. 잡은 날 = 그날 피크 근처 시각 중 하나라도 경보가 걸린 날. 재현율(날) = 잡은 날 ÷ 피크 근처 날.
- 합격: 재현율(날) ≥ 80% 그리고 하루 헛경보 ≤ 1. 함께 표시: 마진 없음(m=0)·기본 m만 사용·조건별 마진, 칸 재현율, 8/2\~8/13(휴무·재가동 주)과 나머지 따로.
- 8월 결과로 마진을 고치면 변경 내용과 이유를 기록(세부 조정은 8월 이후 별도 단계, 이번 실행은 7월 표 그대로 적용).

## 마진 게이트 실험 규칙 (사용자 지시 2026-10-07, 게이트 결과 열람 전 기록)

- 전력 예측(4모델 단순평균)과 마진 m(7월 95% 기본 m)은 그대로. 새로 학습하는 것은 "마진을 켤지"를 정하는 게이트(피크 근처 확률)뿐.
- 경보 = ŷ ≥ 0.9·b_origin 이거나 (게이트 p ≥ τ 이고 ŷ ≥ (0.9 − m)·b_origin).
- 대상 구간: 1h·4h·8h. 학습 자료: 3\~7월 각 달을 그 달 시작 전 정답으로만 학습한 4모델(7월 선정 설정, RF 포함)의 예측. 부스팅 나무 수는 각 달 시작 전 복사 안 된 날 14일 확인 구간.
- 게이트 정답: 맞힐 칸 y ≥ 0.9·b(t). 복사된 날의 칸은 게이트 학습에서 제외(인위 자료). 입력: 발행 시점에 알 수 있는 값(ŷ/b, 4모델 예측 퍼짐, 최근 전력/b, 시각·요일·날 종류, 계획 생산량, lead, 월 경과일, 전날 생산 0 여부 등).
- 게이트 모델: LightGBM 이진 분류, 설정 고정(탐색 없음). τ: 3\~7월 달 하나씩 빼는 교차 예측(OOF)에서 날 재현율 ≥ 80%를 만족하는 τ 중 하루 경보 시간이 가장 적은 값.
- 평가: 8월(1\~7월 학습 모델 예측)에서 가동 중 칸 AUC(게이트 p vs ŷ/b), 날 재현율, 하루 헛경보(60분 묶음·run60), 하루 경보 시간, 적중률. 마진 상시 켜짐·게이트만 경보와 비교.

## 선형 조건부 마진 (사용자 지시 2026-10-07 "조건부 마진으로 ML만, 선형회귀", 8월 채점 전 기록)

- 마진 m(x) = 선형 분위수 회귀(q = 0.95, 규제 없음)로 피크 근처 칸(y ≥ 0.9·b_origin)의 r = max(0, y−ŷ)/b_origin을 예측. 0\~0.89로 자름.
  평균 회귀(OLS)는 평균 r을 맞춰 마진이 작아지므로 쓰지 않음(기존 마진과 같은 95% 기준 유지).
- 입력(F1 컬럼, 맞힐 칸 기준, 표준화): 기온·습도·풍속·강수량·생산량(그 시간 값), 하루 중 시각 sin·cos, 날 종류(평일/토/일·공휴일 원핫), lead(시간).

## 서브 출력: 잔차 경로 분포 피크 초과확률 (사용자 결정 2026-10-07 23:50 KST, 실행·9월 열람 전 기록)

- 역할: 마진은 회귀(점예측) 경로의 경보 버퍼, 피크 확률은 전력 예측에 덧붙이는 서브 출력. 둘은 같은 경보를 두고 경쟁하지 않는다.
- 방법: 잔차 경로 분포만 사용(E0 raw, 보정 없음). RF 잎 분포·직접 분류기는 사용하지 않음. 시뮬레이션은 같은 분포의 근사라 경로 표시용으로만.
- ŷ: m1007 4모델 단순평균. 표본 = 원점별 완전한 오차 경로 e = y − ŷ (H칸 묶음).
- 주 사건: 시점 P(y(t+h) > b_origin), 기간 P(경로 중 한 번이라도 y > b_origin). b_origin = max(170, 이번 달 발행 전까지 최고), 엄격한 >, 경로 안에서 b 갱신 없음. 보조: ≥ 0.9·b_origin.
- 오차 풀 원천: 달별 굴리기 OOF(3월\~, 4d 5월\~), 복사된 날 칸 제외. 달 m 풀에는 정답 끝(t+H) ≤ m 시작인 원점만 포함. 풀은 달 시작에 갱신하고 달 안에서는 고정.
- 검증: 1h\~24h 5·6·7·8월, 4d 7·8월(마진 굴리기와 같은 달). 후보 = 풀 창 (가) 이전 전체 (나) 직전 2달. 구간별 합친 score(0.5×시점 Brier + 0.5×기간 Brier) 낮은 창, 동률이면 (가). 과거 빈도 기준선보다 나쁘면 그 구간은 확률 미제공.

## 4.7 보고서 절차 + 판정 2개 병기 (사용자 결정 2026-10-08, v2 요금 시간대 결과 열람 전 기록)

## 드문 피크 사건용 새 확률 모델 (사용자 지시 2026-10-08, 실행 전 기록)

- 목적: y > b_origin(기간 사건)을 현행 잔차 분포보다 잘 구분·예측하는 모델. 근거: 극값이론(EVT) 꼬리 모형화 문헌(예: arXiv 2510.19052, Forecasting and Assessing Risk of Individual Electricity Peaks), 드문 사건 직접 분류.
- 후보 3개(원점 단위 기간 확률, 6구간):
  - M1 직접 분류기 LightGBM(이진, 가중치 없음, 설정 고정: 300 나무, lr 0.03, 잎 15, min_child_samples 50, subsample 0.8, colsample 0.8, λ=1, seed 42).
  - M2 드문 사건 로지스틱 회귀(표준화, L2 C=1.0, 같은 입력).

## ML 구간 모델 이어붙이기 + 최종 마진 (사용자 지시 2026-10-08, 실행 전 기록) — 3단계, ML만

- 구간 모델 = ML ENSEMBLE_C 대표(7월 공통 C로 선정, 변경 없음). 최종 마진 = R1(구간별 7월 칸 95% r, 요금 시간대, 7/13·7/15 제외): 1h 15.6% · 4h 15.9% · 8h 17.1% · 12h 17.4% · 24h 19.3%.
- 이어붙이기: 매시 정각 발행 o마다 lead 1\~4 = 1h 모델, 5\~16 = 4h, 17\~32 = 8h, 33\~48 = 12h, 49\~96 = 24h 모델의 같은 발행 예측을 이어 하나의 24시간 경로로 만든다. 각 칸의 경보 = ŷ_구간 ≥ (0.9 − m_구간)·b_origin.
  - 확인: 같은 (발행, 맞힐 칸)의 y·b_origin이 구간 파일끼리 같아야 한다.
- 비교: 누적 이어붙이기 ① 1h ② 1h+4h ③ \~8h ④ \~12h ⑤ \~24h(전체), 그리고 단독 24h 모델(lead 1\~96 전부 24h 모델, 24h R1 마진).
- 채점: 8월(주), 7월(참고, 마진 원천 달). 팀 판정 + v2 요금 시간대. 함께 이어붙인 경로와 단독 24h 경로의 점 예측 RMSE(lead 구간별, 8월).
- 9월은 이번에 쓰지 않는다(4단계에서 별도). 8월 결과로 구간 경계나 마진을 바꾸지 않는다.

### S2 확률 보정 (사용자 지시 2026-10-08, S2 보정 상태 열람 후 설계, 실행 전 기록)

- 문제: S2 기간 확률이 중간대(5\~20%)는 과대, 높은 대(20% 이상)는 과소. 순위(AUC)는 유지되나 숫자를 확률로 읽기 어려움.
- 제약: 5·6월은 1h\~24h 초과 사건 0 → 시간 순서 보정은 7월까지 불가.
- 방법(구간별, 모든 원점 사용): 주 = Platt 보정(로지스틱: logit(p_S2) → 실제 초과, 2개 모수, 순위 보존). 참고 = 등위 회귀(isotonic, 0\~1 범위).
- 평가:
  - (가) 주 결과 — 9월 B판: 보정 함수를 검증 5\~8월 S2 예측 전체로 적합 → 9월 B판 S2에 적용(시간 순서 지킴).
  - (나) 참고 — 검증 안 달 하나 빼기 교차(LOMO, 5\~8월): 남은 달로 적합 → 뺀 달에 적용. 미래 달 정보를 쓰므로 참고로만.
- 지표: 평균 예측/실제 비율, 확률 구간별 예측·실제(신뢰도 표), 기간 Brier, log loss, 새 피크 AUC(Platt는 불변 확인). 보정 후에도 제공 판정(새 피크 AUC 기준)은 그대로.
- (사용자 확인 2026-10-08) 3단계 "구간 모델 이어붙이기"는 **역할별 연결(결과보고서 4장 표 4-1 방식)**을 뜻한다. ST01(예측 경로를 합친 ML 이어붙이기, reports/20261008T145425_KST_m1007_ml_stitch)은 참고 기록으로만 두고 보고서에 쓰지 않는다.
- 결과(2026-10-08 15:05): 보정 미채택. 9월에서 Platt는 12h만 소폭 개선, 등위 회귀는 4h만 개선·12h 이상 악화. 확률-빈도 관계가 달마다 달라(20\~50% 구간 실제 비율 검증 63\~75%, 9월 0%) 보정이 안정적이지 않음. S2는 상대적 위험(순위) 지표로 표시. reports/20261008T150413_KST_21b134_m1007_s2_calibration
