- 작성 2026-10-06 KST. 결정: 사용자. 근거 정리: Claude. 새 모델 학습 없이 기존 저장 결과만 분석했다.
- 이력: 같은 날 초안(근거 미정리)을 이 문서로 대체했다. 초안의 "전체 결과 열람 전 작성" 문구는 사실이 아니게 되어 삭제했다. 월 제거 피처 비교 run `20261006T225509_KST_1718bb_feature_sequence`의 결과를 이 문서 작성 전에 열람했다(아래 표 5).

## 결정

월 제거(no_month_v1) 재실행에서 RF 하이퍼파라미터 튜닝은 6구간(1h·4h·8h·12h·24h·4d) 모두 **F2 하나만** 수행한다.
F1→F2→F3 고정 설정 비교(1718bb)는 튜닝 입력 선정에 쓰지 않고 참고 결과로 함께 보고한다. "선정 F 튜닝 + F2 강제 튜닝" 2단 방식은 폐기한다.

## 근거 2. RF의 F2 열세는 정보가 아니라 출력 구조에서 생긴다

RF 고정 설정 비교(830be7, 월 포함)에서 8·12·24h는 F1이 더 좋았다. 같은 예측을 리드(발행 후 경과 시간)별로 나눈 RMSE(kW, 7·8월 셀 합산):

| 리드 | 8h F1 / F2 | 12h F1 / F2 | 24h F1 / F2 |
|---|---|---|---|
| 0–1h | 20.09 / **12.53** | 18.16 / **13.62** | 26.72 / **17.35** |
| 1–2h | 19.10 / **15.01** | 17.37 / **15.59** | 25.68 / **18.70** |
| 2–4h | **18.19** / 18.59 | **16.89** / 21.37 | 23.85 / **22.81** |
| 4–8h | **17.42** / 26.44 | **15.94** / 32.81 | **20.65** / 31.34 |
| 8–12h | – | **16.16** / 43.83 | **18.08** / 40.75 |
| 12–24h | – | – | **17.65** / 38.32 |

- 최근 전력 정보(F2)는 RF에서도 **앞쪽 리드 오차를 줄인다**: 0–1h 25\~38%, 1–2h 10\~27% 감소. 열세는 4시간 이후 리드에서만 생기고, 리드가 멀수록 커진다.
- 현재 RF는 원점 하나에 전체 경로(H개)를 한 번에 내는 다중 출력 트리다. 분기 구조를 모든 리드가 공유하므로, 앞쪽 리드에 강한 최근 전력 분기가 먼 리드 예측까지 지배하는 것으로 해석된다(해석이며 직접 검증하지 않음). 부스팅은 원점·리드를 행으로 쌓고 `horizon_step`을 입력해 리드별로 다르게 쓸 수 있으며, 같은 F2 정보로 전 구간에서 이득을 봤다.
- 다중 출력(MIMO)과 직접(direct) 전략은 경로 의존성 보존과 리드별 유연성 사이의 절충이 있다는 것이 다단계 예측 비교 연구의 정리다([Ben Taieb 외 2012, Expert Systems with Applications 39(8)](https://www.sciencedirect.com/science/article/abs/pii/S0957417412000528)). 이 연구는 다중 출력이 일반적으로 열등하다고 보지 않으므로, 여기서는 "이번 데이터·설정에서 관측된 현상"으로만 기술한다.
- 리드별 표는 `experiments/random_forest/20261005T193713_KST_830be7_feature_sequence/<profile>/<F>/<m07|m08>/predictions.csv.gz`에서 계산했다.

## 근거 3. 결합 모델과 최종 비교에서도 F2가 이겼다

- 월 포함 앙상블(f4b4c8·de2e36)의 구간별 최저 C 모델은 6구간 모두 F2 입력이었다.
- 같은 결합 절차의 튜닝 RF+세 부스팅에서 F2가 F1보다 낮았다. 8h 15.45 대 16.67, 12h 16.16 대 16.37, 24h 18.20 대 18.52 kW.

## 근거 4. 운영 정보 조건

F2 = F1(생산·기상·달력) + 발행 시점에 이미 관측된 최근 전력(최신값, 1h·24h 시차, 1h 이동통계). 발행 시점에 실제로 알 수 있는 정보만 쓴다. F3는 주간 패턴·장기 통계로 더 긴 이력 지원이 필요하고, 근거 1에서 일관된 이득이 없었다.

## 주장할 수 있는 것과 없는 것

- 주장 가능: "같은 정보로 학습한 부스팅 3종은 6구간×3모델 전부, 결합 모델은 6구간 전부 F2가 최선이었다. RF에서도 F2는 단기 리드 오차를 줄였다. 따라서 모델 간 비교와 앙상블의 공통 정보 조건으로 F2를 고정했다."
- 주장 불가: "F2가 RF 단독에 최적인 입력이다." 8·12·24h RF 단독은 F1이 더 좋다. 이 열세는 표에 그대로 보고한다.
- 사전 등록이 아니다. 근거 1\~5는 모두 F2 고정 결정 이전의 결과이며, 같은 7·8월 개발 검증을 썼다. 9월은 독립 테스트가 아니다.
- 개선 여지: 8\~24h RF의 F2 열세는 출력 구조 문제로 보인다. 부스팅처럼 리드를 행으로 쌓는 RF나 리드 구간별 RF가 대안이며, 이번 범위에서는 실행하지 않는다.
